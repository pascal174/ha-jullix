# Jullix EMS

Integreer je **Jullix energiebeheersysteem** rechtstreeks in Home Assistant.

## ✅ Wat krijg je?

- **Lokale polling** — razendsnel, geen internet nodig
- **Optionele cloud-data** — voor extra details via de Jullix platform-API
- Alle entities netjes gegroepeerd onder één **Jullix EMS** device
- Volledig configureerbaar via de UI — geen YAML nodig

## 📊 Beschikbare sensors

- Zonnepanelen: vermogen & totale energie
- Batterij: vermogen, SOC, spanning, geladen/ontladen energie
- Slimme meter: net vermogen, import/export tarieven T1/T2, spanning L1/L2/L3
- Water: verbruik
- EV-lader: vermogen, SOC, temperatuur, stroom, status

## 🔧 Vereisten

- Jullix gateway bereikbaar op je lokale netwerk
- Home Assistant 2024.1 of nieuwer
